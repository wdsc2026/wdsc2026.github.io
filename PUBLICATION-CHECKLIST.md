# Publication checklist

- [ ] Create and test the submission portal.
- [ ] Confirm the exact deadline time zone.
- [ ] Add the workshop registration URL and policy.
- [ ] Confirm the venue and room.
- [ ] Confirm invited speakers before publishing names.
- [ ] Confirm program committee members before publishing names.
- [ ] Add accepted contributions after notification.
- [ ] Update `lastUpdated` in `assets/config.js`.
- [ ] Test all external links.
- [ ] Test the site on a phone and desktop browser.
